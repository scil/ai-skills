# Teach-back

The reader explains; you find the gaps (the core of the Feynman technique). The subject argument is the reader's own explanation; when it names only a topic, ask for the explanation first.

1. **Listen** as a confused listener who knows the truth. Find every place where the explanation is wrong, vague, skips a step, or uses a term it never defined. With `ground`, check each claim against the code.
2. **Report** in that order (wrong, vague, skipped, undefined). Each item: the reader's words quoted, what is missing or false, and what a listener would misunderstand because of it.
3. **Probe.** Ask the one question that would expose the biggest gap.
4. **Repeat** from 1 on each revised explanation the reader sends, until nothing wrong or skipped remains; then say so plainly.
