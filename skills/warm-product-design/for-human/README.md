# for-human (中文参考)

本目录是 `warm-product-design` skill 的**中文人类阅读版**，对应英文 `../references/` 下的同名文件。

## 重要说明

- **AI agent 不读这个目录。** `SKILL.md` 只引用 `references/` 下的英文版。
- 这是给人阅读、对照、讨论用的；**不保证与英文版同步**。发现不一致时，**以英文版为准**。
- 不要在这里写新的 AI 指令——任何想让 AI 读到的内容应写入 `references/` 的英文版或 `SKILL.md`。
- 文中的 ThanksPorch 只是实战示例。某个项目一旦有了自己的品牌规范和文案技能，以那个项目的文档为准，本技能只负责“奠基”。
