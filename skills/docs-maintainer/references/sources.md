# Sources

last-refresh: 2026-09-15
gate-days: 30

Same tiering as `ai-agents-md/references/sources.md`, and read by the same script (`ai-agents-md/scripts/check-sources.ps1 -Path <this file> -GateDays 30`). The gate is 30 days, not 7: documentation standards (C4, MADR, OpenAPI, llms.txt) move slowly; the vendor pages on skills and plans move faster and are the ones to read first when the script says CHANGED.

| Tier | kind prefix | Decides / corroborates / illustrates / points |
|---|---|---|
| 1 | `T1-vendor` (harness vendors) · `T1-standard` (the standard's own site) | **Decides.** Enters on its own. Vendor and standard disagreements are recorded, and the node follows the harness or standard it is read by. |
| 2 | `T2-research` | **Corroborates or qualifies.** Two independent studies, or one that explains a Tier 1 rule. One study alone is "one study finds". |
| 3 | `T3-exemplar` | **Illustrates.** None registered yet; add a public repository whose `docs/` is organized for agents when one is found. |
| 4 | `T4-report` | **Points.** A vendor's first-hand engineering post counts as T4 with weight. |
